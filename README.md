# CITYPROOF

«Аким на 5 часов» — лаборатория городских сценариев для HackAlem AI.

Пользователь выбирает пять мероприятий в бюджете 100 условных единиц, исследует показатели пяти районов и проверяет план с агентом. Источники — синтетический датасет организаторов, а не статистика реальной Астаны.

Слева — компактный каталог решений, в центре — интерактивная карта Астаны (Leaflet), справа — рабочая панель агента. Светлый бело-синий интерфейс связывает выбор района и показателя с расчётами. Карта показывает шесть районов OSM; пять сопоставлены с неизменными ID учебной модели, Сарайшық имеет `null` и сообщение «Не входит в учебный набор данных». Соответствие по названию — учебная визуализация, не реальная статистика территории.

Границы получены из OSM API 23.09.2026; исходные relations, версии, лицензия ODbL, запрос и воспроизводимая подготовка сохранены в [data/geography/README.md](data/geography/README.md). Это не официально заверенные границы. Соответствие изменениям августа 2026 не подтверждено; южный участок городской границы площадью около 10,995 км² не покрыт шестью районными relations и показан пунктиром без выдуманного назначения.

## Быстрый запуск

Node.js 22.x, npm. Проверенная среда разработки: Node 22.23.2, npm 10.9.8.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Нажмите «Пример из задания», затем «После решений» или «Учебная зима». Нажатие на показатель района раскрывает арифметику.

Для настоящего агента скопируйте `.env.example` в `.env.local` и задайте **локально** `OPENAI_API_KEY` и `OPENAI_MODEL`. Опциональный `OPENAI_BASE_URL` нужен только для согласованного совместимого endpoint. Значения не передаются в браузер, не публикуются в Git и не должны отправляться в чат. Перезапустите сервер после настройки. Приложение использует Responses API с function calling и structured outputs; доступность конкретной модели требуется проверить, название режима Codex не является API model ID.

```sh
npm test
npm run typecheck
npm run lint
npm run build
npm start
# HTTP-интеграционные проверки с запущенным сервером:
npm run test:e2e
# С запущенным сервером и настроенным API (расходует API-квоту):
npm run test:agent
```

## Архитектура и достоверность

Одно Next.js-приложение: React/TypeScript, Tailwind, Leaflet + локальный GeoJSON, серверные Route Handlers, Zod и официальный OpenAI SDK. Чистый движок используется интерфейсом, сервером и тестами. Сервер принимает решения, но не клиентские коэффициенты или стоимость.

Правила: ровно пять разных мер, не больше двух на направление, бюджет не выше 100, район обязателен только для районных мер. M1/M3 несовместимы глобально; M4/M7 и M5/M13 — только в одном районе. Подробный DOCX допускает минимум три направления; используем эту трактовку вместо предположения об обязательном покрытии всех пяти. Это не подтверждённый ответ ментора.

Эффекты учитывают лаг `(8 − L) / 8`; синергии фиксированы. После суммирования применяется clip [0,100], затем веса показателей и доли населения. Score = 0.7 × среднее города + 0.3 × минимум района − число пар район/показатель строго ниже 40. Промежуточного округления нет; недопустимый план не получает Score.

Учебная зима `winter_demo` — отдельное допущение команды: T1 −4 и C1 −8 во всех районах после официального расчёта. Исходный результат не меняется, повторный запуск не накапливает шок. Это не прогноз, оценка вероятности или доказательство безопасности. Дополнительной защиты отдельных мер от зимы нет.

## Агент

Инструменты: `get_model_rules`, `evaluate_scenario`, `run_stress_test`, `get_evidence`. Модель запрашивает инструменты, сервер исполняет их и возвращает результат. Финальные численные фразы собираются сервером из выбранных моделью проверенных ссылок; произвольные численные утверждения модели не отображаются. Пользователь может задать свой вопрос и уточнить ответ в рамках текущего плана.

Лимиты: 6 обращений к модели, 8 инструментальных вызовов, 45 секунд на запрос. Не больше двух одновременных анализов, 6 запросов в минуту на сессию и 20 глобально на процесс. Запуски изолированы сессионной HttpOnly-cookie, хранятся в памяти до 20 минут; серверный перезапуск их сбрасывает. Для демонстрации используется один локальный процесс. Это не полноценная защита публичного сервиса от расходов; публичное размещение не выполнено.

При отсутствии API расчёт и зимний эксперимент доступны, панель честно показывает недоступность агента. Обязательный продукт не считается полностью принятым до успешной проверки настоящего API. Текущий статус и реально выполненные проверки — в STATUS.md.

Проверка связи объяснений с числами не основана на поиске цифр в свободном тексте: модель возвращает тип утверждения и ссылки на расчёты. Сервер проверяет принадлежность результата текущему запуску, факт вызова нужных инструментов, получение evidence и наличие конкретного эффекта. Затем сам строит численный фрагмент, включая точные коэффициенты лага. Неподтверждённый ответ возвращается модели на исправление в пределах общего лимита; если исправление не получилось, пользователь видит ошибку, а не выдуманный вывод.

## Демонстрация и приёмка

1. Откройте приложение и нажмите «Пример из задания». Это исходный пример, не рекомендация.
2. Проверьте стоимость 95 и официальный Score 56,54. В Нуре выберите B1: журнал показывает эффект M10 и отдельную синергию M10+M12.
3. Переключитесь на «Учебная зима», выберите Сарыарку и C1: официальный результат 47,5, учебное изменение −8, итог 39,5. Официальный Score остаётся доступен отдельно.
4. При настроенном API задайте свой вопрос, например: «Проверь план с зимой и объясни C1 в Сарыарке». Дождитесь настоящих операций в журнале, откройте доказательство и задайте уточнение. Этот шаг требует реальной API-квоты.
5. Измените меру: старый анализ должен исчезнуть. Удалите одну меру: числовой Score сценария становится недоступен.

`npm test` проверяет ядро, инструменты, объяснения и изоляцию запусков. В агентных unit-тестах используется явно тестовый транспорт, не живой провайдер. `npm run test:e2e` запускает HTTP-интеграционные проверки через Playwright request API без браузера. Визуальная проверка и взаимодействия выполняются отдельно в браузере. `npm run test:agent` запускает реального провайдера через работающий сервер, проверяет оба расчёта, evidence и дополнительный вопрос; без настроек завершается с кодом 2 и сообщением BLOCKED.

## Материалы и сдача

`sources/` — исходные документы организаторов; `hackalem_model.json` — их машиночитаемая производная; `stress_events.json` — допущения команды. `DATA_CHECK.json` относится только к подготовке данных, а не тестам приложения.

Итоговый код размещается только в командном репозитории BAITC-Hacks/hack-8d88351c-eam-trinity. Рабочая ветка или PR не означают обновление main. После публикации отдельно нужно нажать «Сдать решение» на платформе хакатона.

Имена и личный вклад участников пока не предоставлены; авторство не выдумывается. A/B, экспорт, оптимизатор и дополнительные кризисы не реализованы.


## Проверка карты

Масштаб и перемещение работают средствами Leaflet. «Весь город» возвращает полный административный контур. Шкала индексов 0–100 одинакова во всех режимах; серый район означает отсутствие данных, синяя обводка — выбор. На общем масштабе подписи компактны; численные значения доступны в карточке и при приближении.

Подложка — стандартные тайлы OpenStreetMap с обязательной атрибуцией, без массовой загрузки и офлайн-кэша. Overpass при открытии не вызывается. При отказе тайлов локальные полигоны и расчёты остаются доступны. Воспроизводимая проверка: `npm run build`, `npm start -- --port 3001`, затем в другом терминале `node scripts/qa-no-tiles.mjs` и открыть http://127.0.0.1:3002. Этот локальный QA-прокси блокирует внешние изображения через CSP; для обычной работы используйте порт 3000/3001.
