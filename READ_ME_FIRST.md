# CITYPROOF — обновлённый пакет FINAL-2

Это задание и исходные материалы для разработки, НЕ готовое приложение.

## Что сделать
Распакуйте содержимое архива в корень командного репозитория, открытого в Codex. Если вы уже распаковали старый пакет и не редактировали его материалы, замените одноимённые файлы пакета. Не удаляйте существующий код приложения, .git или чужие изменения. Не создавайте вложенный репозиторий.

Если вы работаете в Codex Cloud, локальная распаковка сама по себе не передаёт файлы в удалённую среду: материалы должны быть загружены в выбранный командный репозиторий/доступную задаче среду до запуска. Проверьте, что Codex видит CITYPROOF_START.md и JSON.

Отправьте Codex текст из COPY_TO_CODEX.txt. Старые промпты отправлять не нужно.

## Содержимое
- CITYPROOF_START.md — полное единое задание: настоящий агент, изометрическая сцена, расчёт, дизайн, проверки, GitHub.
- COPY_TO_CODEX.txt — стартовый промпт, совпадающий с текстом в ответе.
- hackalem_model.json — производная исходного датасета для реализации; данные не изменены в этой версии пакета.
- stress_events.json — дополнительные учебные допущения; НЕ коэффициенты организаторов.
- sources/ — четыре исходных документа организаторов.
- DATA_CHECK.json — отчёт проверки подготовки данных, сохранённый из предыдущего пакета; НЕ тесты будущего приложения.
- PACK_MANIFEST.json — состав/контрольные суммы файлов этого пакета; проверка упаковки, не работоспособности продукта.

## GitHub и сдача
В промпте поручены commits и публикация в существующий командный репозиторий с проверкой факта отправки. Прямой push может зависеть от среды и прав. В Codex Cloud публикация может потребовать Create PR и последующего Merge человеком. Нельзя считать локальные файлы или открытый PR автоматически обновлённой основной веткой.

Правила требуют личного вклада каждого участника. Не выдумывайте авторство. Тестирование, документация и демонстрация должны быть фактической работой.

После публикации последней версии отдельно нажмите «Сдать решение» на странице кейса и заполните название/описание. Архив сам по себе ничего в GitHub не публикует и решение за вас не сдаёт.
