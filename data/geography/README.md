## Проверка актуальности

[Управление архитектуры Астаны](https://www.gov.kz/memleket/entities/astana-saulet/press/news/details/1274528) перечисляет шесть районов после уточнения границ. Новые официальные изменения приняты 14 августа 2026 года: [№459](https://maslihat01.kz/source/uploads/resheniya_8sozyv/459-ru.pdf), [№460](https://maslihat01.kz/source/uploads/resheniya_8sozyv/460-ru.pdf). Геометрическое соответствие OSM этим актам **не подтверждено**; площади отдельных районов отличаются. Наличие свежих OSM edits не означает, что изменения официальных актов полностью внесены.

Шесть доступных районных геометрий покрывают 786.378 км² из 797.373 км² городской геометрии OSM. **Южный отдельный участок 10.995 км²** (bbox `[71.3667047, 50.8576076, 71.4425066, 50.886331]`) присутствует в городской relation, но отсутствует в шести районных relations. Его принадлежность не дорисовывалась; городской контур показывается отдельно. Крупных наложений районов не выявлено; вне границы города — только погрешность вычислений менее 1 м². MultiPolygon и все доступные части сохранены.

На карте показываются учебные показатели **одноимённых** пяти районов. Это не реальные статистические данные показанных территорий и не перенос населения между новыми границами. Сарайшық не входит в учебный набор: показатели отсутствуют, мероприятия не назначаются, расчёт не меняется.

## Воспроизведение

`source/relation-*.json` — полные ответы OSM с relations, ways, nodes и версиями; URL и metadata — в `source/manifest.json`. Сохранён эквивалентный запрос `source/query.overpassql`. Overpass вернул ошибки/тайм-аут, поэтому фактическая выгрузка сделана через доступный OSM API. Запросов к Overpass/OSM geometry при открытии приложения нет.

```sh
npm ci
npm run geo:prepare # только локальные сохранённые inputs; полностью воспроизводимо
# Осознанное обновление источника с сетью, затем обязательная ручная проверка diff:
npm run geo:fetch
npm run geo:prepare
```

Подготовка: osmtogeojson собирает way/node members в Polygon/MultiPolygon без упрощения или ручной коррекции. Проверяются замкнутость колец, валидность, конечные координаты, bbox Астаны, согласованность общих OSM объектов, вложенность, наложения и полнота ID. Polylabel вычисляет внутреннюю точку подписи в проекции Mercator на крупнейшей части района. `validation.json` содержит отчёт, площади, точки подписей и SHA-256 inputs. Результат: `public/geography/astana-districts.geojson` и `astana-city.geojson`.

Только Leaflet используется в браузере. Остальные геобиблиотеки — инструменты подготовки/проверки, не картографические движки. Override xmldom 0.8.15 устраняет уязвимую транзитивную версию конвертера; JSON-путь конвертации проверен.

Подложка: стандартные OSM tiles, [условия использования](https://operations.osmfoundation.org/policies/tiles/). Прямые браузерные запросы с обычным Referer и HTTP-кэшем; без prefetch, массовой выгрузки, прокси, офлайн-архивирования и платных ключей. Наличие сети и доступность тайлов не гарантированы. Атрибуция остаётся видимой и без подложки; локальные полигоны продолжают работать.
