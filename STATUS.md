# CITYPROOF — текущее состояние

Рабочая ветка: `codex/cityproof`. Единственный проектный origin: `BAITC-Hacks/hack-8d88351c-eam-trinity`.

## Реализовано

- Финальная полировка AI: отдельные сообщения пользователя и агента, история текущей вкладки, анимированный статус реальных операций, структурированный ответ с детерминированными числами, свёрнутое по умолчанию evidence. Переход карты плавный; подтверждение выполнения приходит после окончания движения.
- Светлый бело-синий интерфейс: решения слева, настоящая Leaflet-карта Астаны в центре, работающий агент справа. Evidence раскрывается под картой и не закрывает агента.
- Локальные проверенные геометрии шести районов OSM. Пять явных сопоставлений с неизменными model districtId; Сарайшық → null, без показателей и назначения мероприятий. Источники, лицензия, версии, raw relations и подготовка — `data/geography/`.
- Масштабирование, перемещение, разные hover/selection, внутренние подписи, «Весь город», переключение метрик/результатов, единая шкала 0–100, атрибуция, честная работа без тайлов. Overpass при открытии не вызывается.
- Реальный `show_evidence_on_map(evidence_id)`: строгие аргументы, текущая сессия и снимок, фактически полученное evidence, выполненные расчёты, сверка явно указанного района/показателя/режима. Словарь модели передаётся агенту в каждом вопросе.
- Структурированная команда проходит через прежний NDJSON. Браузер сверяет её с текущими расчётами, выбирает район/метрику/режим/evidence и отдельно подтверждает выполнение. Журнал различает запрос, выполнение и отмену; сервер не имитирует управление браузером.
- Обычное объяснение не перемещает карту. Ручная кнопка остаётся. Отмена, смена плана/зимы, новый вопрос и ручное управление отвергают устаревшие команды. Повторная команда внутри вопроса не двигает карту снова.

## Реально выполненные проверки — 23.09.2026

- 78 тестов: прежнее ядро/объяснения/сессии, геометрия и SHA источников, сопоставления, отсутствие данных, неизменность результатов, серверные ограничения показа, строгие команды, неправильный режим/показатель/район, отрицание и цитирование, повтор, отмена позднего ответа; дополнительно восстановление диалога, честные статусы и детерминированные бюджет/риски ответа.
- 7 production HTTP-проверок. TypeScript, ESLint и production build прошли; production запущен командой README на http://127.0.0.1:3001.
- Реальный API smoke test прошёл: расчёт → зима → evidence → show-команда C1 Сарыарки → проверенный ответ; обычный уточняющий вопрос не создал команду карты.
- После финальной полировки на production повторён настоящий API-сценарий Сарыарка/C1/зима: немедленное сообщение пользователя, живой статус, фактические операции, подтверждённый переход, свёрнутое evidence и раскрытие 47,5 − 8 = 39,5. Уточнение про B1 Нуры получило 55 → 67,5, M10 +10,5 и синергию +2; оба сообщения сохранились, обычное объяснение не переместило карту. Enter отправляет вопрос. Экран 1366×768 проверен визуально, горизонтального переполнения нет; AI-панель 360 px, центральная область 712 px.
- В браузере с настоящим агентом: «Покажи изменения ЖКХ в Сарыарке после зимнего события…» → Сарыарка/C1/учебная зима/47,5 → 39,5 → подтверждение браузера → раскрытие арифметики.
- Другой вопрос: «Открой на карте безопасность улиц в Нуре после решений…» → Нура/B1/после решений/55 → 67,5; мера M10 +10,5 и синергия M10+M12 +2. Выявленные ошибки выбора режима/метрики языковой моделью закрыты серверной сверкой цели и словарём в контексте; сценарий повторно прошёл после исправления.
- Обычное объяснение C1 Сарыарки сохранило Нуру/B1/режим после решений; ручная кнопка из ответа затем открыла правильное зимнее evidence.
- Отмена до команды сохранила выбор. Отмена после уже выполненного перехода остановила дальнейший ответ. Удаление M5 во время запроса очистило старый анализ, включило исходный режим и заблокировало анализ при 4 мерах; поздние данные не вернули старое состояние.
- Нажатие «+» во время ответа оставило ручной масштаб/Нуру/исходный выбранный режим: поздняя команда была отменена с явной записью в журнале. Обработчик работает в capture phase, поскольку Leaflet останавливает bubbling клика.
- Сарайшық в карте не показывает чужие или нулевые значения. На вопрос о его C1 настоящий агент получил правило geography и объяснил отсутствие учебных данных, без команды показа.
- Проверены все шесть районов, три режима, устойчивый выбор и hover (4 px/3 px), отсутствие пересечения подписей при «Весь город», отсутствие горизонтального переполнения на 1366×768. Центральная карта имеет ширину 750 px.
- Настоящий отказ загрузки тайлов проверен через CSP QA-прокси: шесть локальных полигонов/подписей, выбор Сарыарки и зимнее C1 39,5 работали с честным сообщением об отказе подложки.
- `npm run geo:prepare` воспроизводит сохранённые геометрии без изменений. Движок, учебные данные, пять расчётных районов и бюджет 100 не менялись. Контрольный Score 56.54307, стоимость 95, зимний Score 53.34307.
- Фактический API-ключ не найден в клиентской production-сборке. `.env.local` исключён из Git; перед commit проверяются индекс и diff без вывода секретов.

## Географические ограничения

Снимок OSM получен 23.09.2026, ODbL. Это не официально заверенные границы. Соответствие официальным изменениям августа 2026 не подтверждено. Южный участок городской relation площадью 10,995 км² отсутствует в шести районных relations: показан пунктиром и не присвоен произвольному району. Учебные показатели одноимённых районов не являются реальной статистикой географических территорий.
